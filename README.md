# Convira - AI Chatbot for WordPress

Convira is a GPT-4 powered AI chatbot platform built for WordPress and service businesses. It handles lead capture, customer support, and appointment booking - 24/7 - without code.

## Quick Setup
1. Sign up at convira.chat
2. Add widget script to WordPress header
3. Sync your content
4. Go live in under 5 minutes

Full guide: https://www.convira.chat/blog/ai-chatbot-wordpress

## Architecture
Convira uses session-based multi-tenancy with RLS for data isolation, vector embeddings per customer, and per-chatbot rate limiting.
